# Employee-Management-System
Employee Management System built using Spring Boot, Thymeleaf, MySQL, Spring Data JPA, and MVC architecture with CRUD operations, validation, search, and pagination features.

## Features

- Add Employee
- Update Employee
- Delete Employee
- View Employees
- Form Validation
- Employee Search
- Pagination
- MVC Architecture
- MySQL Database Integration

 ## Technologies Used

- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- Hibernate
- Thymeleaf
- MySQL
- Maven
